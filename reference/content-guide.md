# content.md 语法 + 每节该写什么

`report_builder.py` 读一份 Markdown 当成报告正文。语法很小，掌握下面这张表就够。

## 语法

| 写法 | 生成效果 |
|---|---|
| `# 一、实验目的` | 开一个小节。编号可省（`# 实验目的` 也行），脚本统一写成 `一、实验目的`…`七、思考题`；另有 `# 原始数据记录表` 走最后一页（默认不排表格，加 `--rawdata-table` 才印）。**七个小节连续排版，各节之间不分页**（封面、预习试卷、原始数据记录表才各自单独占页） |
| `## 2.1 光速测量的历史。` | 二级小标题：加粗、不缩进、与正文同字号（批注6允许，但要全文一致），**必须以句号结尾**。编号与标题照课件的小节写 |
| 普通一行 | 正文段落：不加粗、首行缩进两字、单倍行距、两端对齐（批注7）。**条目前的阿拉伯数字序号（1 、2 ）自动加粗**，（1）（2） 这类括号序号不加粗，序号后的正文不加粗；四、实验内容与步骤、五、数据处理 里的编号条目顶格，六、结果陈述、七、思考题 里的 （1）（2）… 前空两格；# 一、实验目的 里的行整行加粗 |
| `$$h\nu=E_m-E_n$$ (1)` | 居中 Word 公式 + 空四格编号（批注8）。编号写在 `$$` 之后的括号里 |
| `![图1 能级跃迁图。](figures/x.png)` | 居中插图，图下方居中小五号题注（批注11、12）。**题注必须以中文句号结尾** |
| `![图1 能级跃迁图。](figures/x.png){w=8}` | 同上，但把图宽限制为 8 cm（默认按图片原始尺寸、最大 14.4 cm，高不超过 9 cm，避免图题被挤到下一页） |
| `表1 峰值电压表` 换行后接 `\| … \| … \|` | 表题居中写在表**上方**（批注18），表格带边框、首行加粗 |
| 思考题的答案 | 抄完题后**直接写答案，不要写"答："**（脚本会自动去掉行首的"答："）；条目序号加粗 |

表格是标准 Markdown 管道表，第一行是列名（**单位写在括号里**，如 `UG2 (V)`、`IP (nA)`，批注19）：

```
表1 峰值电压与第一激发电位表
| 峰值次数 n | 1 | 2 | 3 |
| 峰值电压 Um (V) | 9.1 | 13.3 | 17.8 |
```

公式是 LaTeX 子集：`\frac{}{}`、`\sqrt{}`、`^{}`、`_{}`、`\left(\right)`、`\overline{}`、`\pm`、`\times`、
希腊字母（`\lambda \Delta \nu \mu`）、`\lg \ln`、`\mathrm{}`、`\text{}`。不要用 `\begin{}` 之类的环境，
遇到不支持的写法脚本会原样输出命令名——生成后看一眼 Word 就知道。

## 题注与引用（硬性，2026-10-13 追加）

- 图题**必须含「图」字**、表题**必须含「表」字**（分别写成 `图N …。`、`表N …`），缺字 `check_report.py` 直接报 ERROR。
- 每个板块（一~七节）内容**结束后空一行**：`report_builder.py` 会在每个非空小节末尾自动补一个空段落，content.md 里**不用**手写空行。
- 每个图 / 表 / 公式的**前一段**必须提到它，格式统一为「…如图1所示」「…如表1所示」「…如式（1）所示」。注意是**前一段**——不要先贴图、再在下一段才写"如图N所示"。正确写法：

```
…流体自左端流入、右端流出，如图4所示。
![图4 二维绕流模型。](figures/fig04-model.png)
本实验采用的主要参数如表1所示。
表1 二维绕流模型的主要参数
| 参数 | 数值 | 说明 |
…
雷诺数的定义如式（1）所示。
$$Re=\frac{\rho v L}{\mu}$$ (1)
```

## 图里的文字也要写进正文（硬性，2026-10-13 追加）

课件里的**仪器照片、导轨图、数据图**上常叠着文字框 / 部件编号 / 面板读数 / 坐标轴符号。
这些在 PPT 里是**矢量文本框**，`extract_ppt.py` 导出或整页渲染成栅格图时**会整体丢掉**——
图从报告里看就只剩一个光秃秃的实物，老师要的信息全没了。所以：

- 凡是这类图，**题注之外还要在正文里用文字复述图内文字**：
  - 仪器图 → 「如图6所示：图中上方是示波器，右侧上方是频率计、其下是控制箱，下方是带有光路的导轨。」
  - 编号图 → 正文写「带有光路的导轨上标有 1~8 的编号，依次装有激光器、声光器件……各编号与部件的对应关系如图7所示。」，
    **图题里列出全部编号对应**：`图7 带有光路的导轨。1 激光器；2 声光器件；3 半透半反镜；4 反射镜；5 斩光器；6 棱镜小车；7 光电接收器；8 导轨。`
  - 数据图 → 坐标轴符号（`t`、`T`、振幅、`Es`）写进正文或题注。
  - 仪器铭牌参数 → 单独一段抄进三节（「仪器铭牌上给出的参考数据为：声光器件标称频率 75 MHz，拍频波标称频率 150 MHz……」）。
- 抄文字的两个来源：`work/ppt/outline.md`（课件文字，最可靠）、原始 PPT 的 slide XML；
  也常能在课件正文段落里直接找到同样的描述。
- 导出后**文字全丢又补不回来**的图（典型：纯矢量"数据处理流程图"），**宁可不放这张图**，
  也别在报告里放一张看不懂的图。

## 从课件到各节

课件（`extract_ppt.py` 输出的 `outline.md`）通常按下面顺序讲，按页码归入报告小节：

| 课件页 | 归入报告 | 说明 |
|---|---|---|
| 实验目的 | `# 一、实验目的` | 2～3 条，写成 `1 ……。` 每条一句 |
| 实验原理（课件里的 2.1、2.2、2.3…） | `# 二、实验原理` + 对应 `## 2.1 …。` | **小节编号和标题照课件**，顺序也一致；课件里没编号但必须写的（如测量方法）续写 `## 2.4 …。`，配图 |
| 实验仪器 | `# 三、实验仪器` | 仪器名称 + 参数 + 现场照片；课件分了小节就照课件的小节标题 |
| 实验内容及步骤 | `# 四、实验内容与步骤` | 步骤按课件顺序，写成 `1 ……。`（顶格）；注意事项用 `（1）…` |
| 数据记录 | `# 原始数据记录表` | 课件给的表格结构照抄成表格备用；**默认不排进报告**（加 `--rawdata-table` 才印） |
| 数据处理要求 | `# 五、数据处理` | 完整报告时按它计算、作图 |
| 思考题 | `# 七、思考题` | 完整报告时抄题 + 作答 |

## 各节写法（对照两份范文）

**一、实验目的**（预习报告就要写全）
每条一个完整句子，动词开头，用句号收尾。范文：
`1 了解弗兰克-赫兹实验的原理和实验方法。` `2 测量汞原子的第一激发电位，证明原子能级的存在。`

**二、实验原理**（最容易丢分，必须有图）
按"物理图像 → 公式 → 装置 → 曲线为什么有峰谷"的顺序组织：
1. 先讲理论假设（玻尔定态/跃迁、费米分布、理查森公式…），引出公式并**编号**；公式里的符号逐个解释。
2. 图放在相关文字之后，正文先写"如图N所示"再放图（批注9）。
3. 讲装置结构与电位分布（哪一段加速、哪一段减速）。
4. 讲清"为什么会出现周期性的峰谷"——这是原理部分的核心逻辑。

**三、实验仪器**
列出仪器名称与型号，抄下课件里的重要参数（频率范围、精度、额定值等），配 2～4 张图：
仪器面板、屏幕界面、连线图、现场照片（批注16）。照片不足时先在课件里找，再考虑让用户补拍。
**图上叠加的文字框（部件名、编号 1~8、面板读数）导出时会丢，要在正文复述、编号对应写进图题**（见上节）。

**四、实验内容与步骤**
按操作顺序分条，一条一个动作，包含关键数值（温度 220 ℃、电压范围 0～60 V、12 个峰值…）
和安全注意（关机顺序、不要让 VG2 过大致使汞管电离）。

**五、数据处理**（完整报告）
> **这一节是全文唯一的"算式区"。所有数据处理都放这里，每条一律「公式 → 代数据 → 结果」三段式；六节里一个公式都不许出现。**

1. `1 原始数据及计算结果如表1所示。` + 表格（原始数据、峰值表、逐差表）。
   **数值一律照用户给的 Excel 原样搬**：行列、单位、有效位数都不动；用户已经算好的中间列
   （`1/T`、`lg(I/T²)`、零场电流 `I` 等）直接用他的数，不要另算一套。
2. 按小标题逐步算，**每步先给公式、再代数据、给出结果**（编号连续）。光拍法测光速的骨架可直接套：

```
1 原始数据及计算结果如表1所示。
表1 B 小车两次波形重叠时的位置
| 测量次数 | B0 (cm) | B2π (cm) |
…
2 求平均位置。
两组读数各测 5 次，取算术平均值以减小随机误差，平均值的计算如式（11）所示
$$\bar{B}_0=\frac{1}{n}\sum_{i=1}^{n}B_{0i},\qquad \bar{B}_{2\pi}=\frac{1}{n}\sum_{i=1}^{n}B_{2\pi i}$$ (11)
把表1中的 5 组读数代入式（11），得 B̄₀ = (0.43+0.52+0.62+0.77+0.95)/5 = 0.658 cm，
B̄₂π = (48.33+48.21+48.17+48.53+48.44)/5 = 48.336 cm。
3 求光程差。
…光拍法测光速的光程差如式（12）所示
$$x=2(A_{2\pi}-A_0)+2(\bar{B}_{2\pi}-\bar{B}_0)$$ (12)
把两次重叠时两小车的位移代入式（12），得 x = 2×(51.00−1.00) + 2×(48.336−0.658) = 195.356 cm = 1.95356 m。
4 求光速。
光速由光程差与拍频的频率决定，如式（13）所示
$$c=x\cdot\Delta f$$ (13)
…代入式（13），得 c = 1.95356 m × 1.5×10⁸ Hz ≈ 2.930×10⁸ m/s。
5 求相对误差。
以真空光速的标准值 c₀ = 2.998×10⁸ m/s 为参考，相对误差如式（14）所示
$$E=\frac{|c-c_0|}{c_0}\times 100\%$$ (14)
把测量值与标准值代入式（14），得 E = |2.930−2.998|/2.998×100% ≈ 2.3%。
6 不确定度的评定。
对 B 小车两次重叠时的 5 组读数分别作 A 类评定，得到平均位置的标准偏差 s(B0)=0.092 cm、
s(B2π)=0.068 cm，则光程差的合成不确定度 u(x)=2×√(0.092²+0.068²)=0.229 cm，相对不确定度
u(c)/c=u(x)/x≈0.12%，即 u(c)≈0.003×10⁸ m/s，所以测得的光速可写为 c=(2.930±0.003)×10⁸ m/s。
```

3. **求平均值这类"看似简单"的一步也要写公式并代数据**（用户 2026-10-13 明确要求），不要直接甩一个平均数。
4. 作图：**用用户在 Excel 里做好的图表**——`extract_excel_charts.py` 导出的 PNG
   （先 `convert` 工作簿为 PDF，再 `render`，再按像素框裁），正文写"如图8所示"、图下方给题注；
   数据来源可写"数据与图均取自原始数据记录"。**不要用 `plot_chart.py` 自己画**
   （除非用户明确说"你帮我画图"）；Excel 里没有需要的图时先问用户要。

**六、结果陈述**（完整报告）
> **这一节是全文唯一的"结论区"，不出现任何公式**（不写 `$$…$$`、不写带等号的算式、不写"由式（N）可得"）。
> 只写**文字 + 最终数值**；算式与代入过程全部留在五节。`check_report.py` 会报 `section.equation-in-conclusion`。

- `## 1 结果总结。`：测量值±不确定度、与理论值比较、相对误差、结论一句话。范文：
  `用光拍法测得的光速为 c = (2.930 ± 0.003)×10⁸ m/s，与真空光速的标准值 c₀ = 2.998×10⁸ m/s 相比，相对误差约为 2.3%。测量结果与课件给出的参考值 2.93×10⁸ m/s 基本一致，说明用光拍法测量光速的方法是正确、可行的。`
- `## 2 分析误差原因。`：逐条列出（第一峰偏大/读数误差/温度波动/参数设置/随机误差/数据处理），
  能定量就定量。**可以数字，但不能列算式。**
- `## 3 应对方法。`：针对上一条每条给一个可操作的做法（批注22，这里是拉开分数的地方）。

**七、思考题**（完整报告）
`## 1 <题目原文抄下来>`，下面一行**直接写答案（不写"答："）**；多问的题目分（1）（2）… 逐条回答，
这些（1）（2）前空两格、序号加粗（批注23）。答案 3~5 行讲清要点即可，不要长篇大论。

**原始数据记录表**
预习报告：空白表格，供打印后手写（列名带单位，行数够用）。
完整报告：把用户给的手写照片用 `--rawdata-image` 附在最后；或把电子数据填进表格。

## plot_chart.py 的 spec.json

> 只在用户明确说"你帮我画图"、或 Excel 里确实没有对应图表且用户同意时才用这个脚本；
> 默认的数据图要从用户的 Excel 里导出（见上）。

```json
{"kind": "scatter_fit",
 "x_label": "峰值次数 n", "y_label": "峰值电压 Um (V)",
 "x": [1,2,3], "y": [9.1,13.3,17.8],
 "fit": {"type": "linear", "x0": 0, "show_equation": true, "show_r2": true},
 "size": [1100, 760]}
```

- `kind`：`scatter_fit`（散点+拟合线，最常用）、`line`（折线，画 Ip~UG2 曲线）、`scatter`、`multi`（多组 `series`）。
- `x0`：让拟合直线过定点（如 `x0: 0` 做外延法求截距）。
- `y_log: true`：对 y 取 log10 后拟合（理查森直线法）。
- 运行后 stdout 会给 `slope / intercept / r2`，直接写进报告文字。
- 图里不要写标题（题注由报告给），坐标轴务必带单位。
